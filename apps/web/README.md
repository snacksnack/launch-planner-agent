# apps/web

Gantt UI for launch-planner-agent (Vite). This is a **placeholder scaffold** —
the interactive Gantt with critical-path highlighting, freeze-window shading,
and the provenance detail panel is built in **P1.7 (RC1-188)**, where we'll
evaluate `frappe-gantt` vs `vis-timeline` and pick one.

```bash
npm install
npm run dev      # expects the API at http://localhost:8000 (override with VITE_API_BASE)
```
