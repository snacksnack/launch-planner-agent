# PRD: Internal Link Shortener

**Owner:** Sam Okafor (Eng) · **Status:** Draft v0.1

## Summary

We want an internal link shortener so people can paste readable links into docs
and chat instead of hundred-character dashboard URLs. Someone submits a long URL,
gets a short one back, and following it redirects.

## Notes

Nothing else is decided yet. We have not picked a domain, we do not know whether
it needs auth, and there is no date attached to this.
