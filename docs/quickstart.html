Quick start

Two terminals, no credentials.

The whole thing runs against a hand-reviewed flagship plan (an on-prem Jira → Cloud migration) with no API key — the UI reads a pre-scheduled plan from the API.

Terminal 1 — the API
# serves the scheduled golden plan by default uv sync --all-packages uv run uvicorn app.main:app --reload # :8000
Terminal 2 — the UI
cd apps/web && npm install && npm run dev # :5173

Open localhost:5173 — the migration renders as a Gantt with the critical path in red. Add LPA_ANTHROPIC_API_KEY only when you want the agents to build a plan from a fresh PRD. Nothing to install? The hosted demo runs the same plan, read-only.

The pipeline

LLM proposes, Python validates, human approves.

Judgment is the LLM's; the math and the gates are deterministic. Nothing reaches Jira — or an exec — without a human in the loop.

Why it's built this way

The plan is an audit trail, not a black box.

01

Provenance is first-class

Every agent-produced entity carries reasoning, a verbatim source quote, and a confidence level — from day one, not bolted on.

02

The engine can't call an LLM

The deterministic core (CPM, float, Monte Carlo, cycle detection, validation) cannot even import the agent code. Enforced in CI.

03

Side effects are gated

Real Jira writes need explicit confirmation and credentials; mock is the default. Status emails are previewed, never auto-sent.
